# Rudransh-Profile
Personal profile webpage that was inspired by guns.lol for experimenting with modern web design, animations, and UI interactivity using HTML, CSS, and JS. It features unique styles and elements designed to improve my knowledge of frontend development.

## Features

-  Modern UI design
-  Interactive elements and effects
-  Responsive design for different screen sizes
-  Real time discod and spotify status
